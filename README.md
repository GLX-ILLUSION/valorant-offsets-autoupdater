# JSON Offsets for Web Offsets Updater

This project is an adaptation of an web offsets updater, based on a CS:GO codebase. It aims to simplify the process of maintaining and updating offsets, ensuring that they are always up-to-date without the need to compile a new loader for your P2C.

## Usage

Follow these steps to integrate the web offsets updater into your project:

1. Download all the files from this repository.
2. Modify the URL in the code as needed or use the provided URL.
3. Compile your project.

Feel free to submit pull requests or open issues for improvements, bug fixes, or new features. Your contributions are greatly appreciated!
